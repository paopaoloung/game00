
# Context
大富翁桌遊玩家

# Objective
生成一個網業玩大富翁時的財富計算工具，用google sheet作數據中轉。

google sheet數據結據：
A6	A (玩家名稱)	B6	B (目前資產)
A7	燈龍魚	B7	20000
A8	小毛蟲	B8	20000
A9	BB軒	B9	18500
A10	玩家4	B10	20000
A11	現金池	B11	0

網業P1包含：
(文字1) 燈龍魚財產： 20000 ---20000為讀取B7的數值
(按鈕8) 現金池現金：0 ---這個按鈕名稱是文字[現金池現金：]+讀取B11的值，生成的。點擊後執行：刷新最新B7值加上最新B11值的和寫入B7值；B11值清空為0；彈出窗口按鈕5：（名稱）領取成功，點擊後關閉按鈕彈窗
(輸入框1) 供用戶入金錢值
(按鈕1) K(千) ---刷新讀取輸入框1數值後乘以1000再輸出/更新結果為輸入框1的數值
(按鈕2) M(百萬) ---刷新讀取輸入框1數值後乘以1000000再輸出/更新結果為輸入框1的數值
(按鈕3) 終點奬金(➕2M) ---讀取B11的數值加上B7的數值，結果寫入B7；B11的值其後清0。完成後彈出窗口按鈕5，輸入框1內容清空。

(按鈕0) 付租金 (➖入現金池) ---清空B11的值為0；刷新輸入框1最新數據，將B7減去輸入框1數值的結果寫入B7，同時將輸入框1的值存入B11，完成後彈出窗口按鈕5，輸入框1內容清空。
(按鈕9) 罸款/買地 (純扣錢) ---刷新輸入框1最新數據，將B7減去輸入框1數值的結果寫入B7；清空B11的值為0；完成後彈出窗口按鈕5，輸入框1內容清空。

現在不要求無感執行，要求輸入網址後，能自動抓取目前的玩家 ID備用，將現金池的金額從0改為2000000，不更改任何用戶的資金，跳出彈窗顯示「終點奬金已備妥...」，5秒後自動關閉、然後刷新開始抓取的玩家 ID的遊戲網業刷新數據
